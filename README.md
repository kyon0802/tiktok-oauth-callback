# tiktok-oauth-callback

株式会社ミズホの TikTok Accounts API 連携で使う、**OAuthコールバック用の静的ページ**です。

```
https://kyon0802.github.io/tiktok-oauth-callback/
```

## なぜ必要か

TikTokのAccounts APIは、アカウント所有者が認可したあとの戻り先URLを要求します。
書式が厳しく、**`https://` 必須・ポート番号不可・末尾は `/`・クエリやアンカー不可**で、
広告主向けと違い `localhost` が使えません。そのため公開URLを1枚用意しています。

## このページがすること

URLに付いてくる `?code=...` を読み取って画面に表示するだけです。

- **通信は一切行いません**。fetch も XHR も無く、**外部URLの読み込みも1つもありません**
  （Webフォントも使っていません。外部読み込みがあると Referer 経由で `?code=` が
  第三者に渡る可能性があるため、意図的に排除しています）
- 保険として `<meta name="referrer" content="no-referrer">` も入れています
- データの収集・保存・送信をしません。アクセス解析も入れていません

認可コードは訪問者自身のURLに含まれるものだけを、その人のブラウザ内で表示します。

## 注意

認可コードはアクセストークンと交換できる鍵です。**URLごと他人に共有しないでください。**
数分で失効します。
